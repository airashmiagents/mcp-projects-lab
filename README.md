# MCP Projects Lab

Small MCP server and client projects built while learning the Model Context Protocol.

| Folder | What it does |
| --- | --- |
| `my-first-mcp/` | MCP server with weather tools (current weather and historical archive) using Open-Meteo. |
| `mcp-sentiment/` | Text sentiment analysis with TextBlob, served through Gradio, plus a chat client that uses MCP tools. |

Each folder has its own dependencies. Run commands from inside that folder with `uv`.
